# Notion Projects

This folder contains Notion-ready project page templates for the portfolio.

## How to use

1. Create a free Notion account at https://www.notion.so.
2. Create a new public page for each project.
3. Copy the content from the corresponding markdown file into the Notion page.
4. Publish the page and get the public share link.
5. Replace the placeholder links in `index.html` with the real Notion URLs.

## Files

- `brand-strategy.md` — Brand strategy project template
- `digital-campaign.md` — Digital campaign project template
- `marketing-analytics.md` — Marketing analytics project template
