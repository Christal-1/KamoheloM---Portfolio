# 03 — Marketing Intelligence: Data That Moves

**Project type:** Analytics concept / portfolio project  
**Focus:** Marketing analytics • KPIs • Insight

## Project overview

A marketing intelligence project exploring how campaign data can become insight, and how insight can become the next strategic decision.

## The business question

Which channels and customer segments are contributing most effectively to campaign performance?

## Suggested data

The project can use:
- Campaign performance data
- Website traffic
- Social media performance
- Customer segments
- Conversion data
- Marketing spend

## Suggested KPIs

- Impressions
- Reach
- Engagement rate
- Click-through rate
- Conversion rate
- Cost per acquisition
- Return on ad spend

## Analysis

Look for:
- Best-performing channels
- Strongest customer segments
- Conversion drop-off points
- Cost versus performance
- Opportunities for optimisation

Place datasets and analysis files in:

`data/`

## Dashboard

The final dashboard can include:

- KPI summary
- Channel performance
- Conversion funnel
- Audience segments
- Spend versus return

Place dashboard files and screenshots in:

`dashboard/`

## Recommendations

The final project should end with business recommendations.

Example:

> Based on the performance data, reallocate budget toward the channels generating the strongest conversion efficiency while improving the consideration stage of the customer journey.

Place final insights in:

`insights/`

## Suggested final deliverables

- Dataset
- Analysis notebook or spreadsheet
- Dashboard
- Insight summary
- Recommendations
